## 🇬🇧 English (default)

**Title:** Chat Folders – Organize & Search AI Chats
**Short description (120/132):** Works with ChatGPT. Organize your chats into folders right in the sidebar. Search, color-code and find any conversation.

**Long description:**

```
Hundreds of ChatGPT chats and no way to find the one you need? Chat Folders adds simple folders right inside ChatGPT's sidebar, so every conversation has a place.

WHAT IT DOES
• Folders in the sidebar – create, rename, color-code, collapse and reorder folders without leaving chatgpt.com.
• One-click add – open a chat, press the folder button and pick a folder. A chat can live in several folders.
• Add many at once – tick the chats you want and add them in one go.
• Drag and drop – move chats between folders and reorder folders.
• Instant search – filter folder names and chat titles as you type.
• Always up to date – when you rename a chat in ChatGPT, the folder updates too.
• Light and dark mode – matches ChatGPT's look.
• Backup – export and import your folders as a JSON file.

FREE VS PRO
Free: 3 folders with unlimited chats, search, colors, drag and drop and backup.
Pro: unlimited folders and sync across your computers (uses Chrome's own sync). Monthly, yearly or lifetime plans. Secure payment through Stripe, cancel anytime.

PRIVATE BY DESIGN
• Your folders are stored only in your browser (or in Chrome sync if you turn it on).
• We never read, store or send the content of your conversations. We only save each chat's ID and title so the folder can link to it.
• No accounts, no tracking, no ads.
• Minimal permissions: storage, and access to chatgpt.com to show the folders.

HOW TO USE
1. Install the extension and open chatgpt.com.
2. You'll see a new "Folders" section above your chats in the sidebar.
3. Click + to create a folder, then open a chat and press the folder button to file it.

Chat Folders is an independent extension. It is not affiliated with, endorsed by or sponsored by OpenAI. ChatGPT is a trademark of OpenAI.

Questions or ideas? Use the support tab — every message is read.
```
